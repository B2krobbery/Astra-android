\# ✨ Astra



\### Modern Matchmaking, Guided by the Stars.



Astra is an Android matchmaking application designed for the Indian audience, combining modern dating and matchmaking experiences with Vedic astrology, horoscope compatibility, profile verification, and AI-assisted astrology guidance.



The application is designed around a simple idea:



> \*\*Find meaningful connections with a little help from the stars.\*\*



\---



\## 📱 Application Overview



Astra combines the familiar experience of a modern dating application with culturally relevant Indian matchmaking features.



Users can discover potential matches, explore detailed profiles, check horoscope compatibility, view profile verification status, connect with matches, and interact with an AI-powered astrology assistant.
